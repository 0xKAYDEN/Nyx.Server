# Fixed: NullReferenceException in EntityTable.SaveEntity

## Problem
After migrating from MySQL to PostgreSQL, a `NullReferenceException` occurred at line 82 in `EntityTable.cs` when trying to save an entity:

```
System.NullReferenceException
  HResult=0x80004003
  Message=Object reference not set to an instance of an object.
  Source=Nyx.Server
  StackTrace:
   at Nyx.Server.Database.EntityTable.SaveEntity(GameClient c, NpgsqlConnection conn) in D:\Nyx\Nyx Last Stable\Nyx\src\Nyx\Database\EntityTable.cs:line 82
```

## Root Cause
1. **EntityRecord.Owner type mismatch**: The `Owner` property in `EntityRecord` was defined as `GameClient` instead of `string`. In the MySQL version, the Owner column stored the username as a string.

2. **Missing Owner assignment in CreateEntity**: When creating a new entity, `client.Entity.Owner` was not set to `client`, causing it to be null.

3. **Incorrect Owner value in SaveEntity**: The code was trying to assign the GameClient object directly to the Owner field instead of the username string.

## Solution
Fixed three issues:

### 1. Changed EntityRecord.Owner type (EntityRepository.cs)
```csharp
// Before:
public GameClient Owner { get; set; }

// After:
public string Owner { get; set; } = string.Empty;
```

### 2. Added Owner assignment in CreateEntity (EntityTable.cs)
```csharp
// Added this line after setting Entity.UID:
client.Entity.Owner = client;
```

### 3. Fixed Owner value in SaveEntity (EntityTable.cs)
```csharp
// Before:
Owner = c,

// After:
Owner = c.Account.Username,
```

### 4. Fixed Owner value in CreateEntity (EntityTable.cs)
```csharp
// Before:
Owner = client,

// After:
Owner = client.Account.Username,
```

## Files Modified
- `src/Nyx/Database/PostgreSQL/EntityRepository.cs` - Changed Owner property type from GameClient to string
- `src/Nyx/Database/EntityTable.cs` - Fixed Owner assignments in SaveEntity and CreateEntity methods, and added missing Entity.Owner assignment

## Verification
The issue occurred when trying to register a new account. After these fixes:
- New character creation should work properly
- The Owner field in the entities table will store the username as a string
- The Entity.Owner property will be properly set to the GameClient object
- No more NullReferenceException when saving entities
