## New Issues to Fix

### Issue 1: Monster Respawn Broken (GameTimer Disposed)

**Error:**
```
System.ObjectDisposedException: Cannot access a disposed object.
Object name: 'GameTimer`1'
   at Nyx.Server.Game.Screen..ctor(GameClient client)
   at Nyx.Server.Client.GameClient.ReadyToPlay()
   at Nyx.Server.Network.PacketHandler.LoadEntity(GameClient client)
```

**Symptoms:**
- Monsters disappear immediately when killed
- Monsters never respawn

**Root Cause:**
The `Screen` constructor tries to start a `GameTimer` that has already been disposed. This likely happens because:
1. The timer was disposed during a previous disconnect/cleanup
2. A new Screen is created but reuses a disposed timer reference
3. The World.Subscribe method tries to start the disposed timer

**Fix Location:**
- `src/Nyx/Game/Screen.cs` line 1321
- `src/Nyx/System/World.cs` line 3170
- `src/Nyx/Utilities/GameTimer.cs` line 178

**Possible Fix:**
- Check if timer is disposed before starting
- Create new timer instances instead of reusing disposed ones
- Add null/disposed check in World.Subscribe

### Issue 2: Packet Size Parsing Error

**Warning:**
```
Packet size too large: 20828 bytes from KAYDEN
```

**Root Cause:**
The `ConcurrentPacketQueue` is reading an incorrect packet size from the buffer. This could be because:
1. The packet data is corrupted or misaligned
2. The encryption/decryption is producing wrong output
3. Multiple packets are being merged incorrectly

**Fix Location:**
- `src/Nyx.Network/ConcurrentPacketQueue.cs` - reviewPacketSize method
- Check packet framing in GameSession.ReadPipeAsync
