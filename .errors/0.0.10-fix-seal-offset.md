# Fix: Packet Seal Validation Wrong Offset

## Problem
Getting `ArgumentOutOfRangeException` when processing packets:
```
System.ArgumentOutOfRangeException: Index was out of range. Must be non-negative and less than the size of the collection. (Parameter 'startIndex')
   at System.BitConverter.ToInt64(Byte[] value, Int32 startIndex)
   at Nyx.Server.Network.PacketHandler.HandlePacket(Byte[] packet, GameClient client)
```

## Root Cause
The seal validation was reading at the wrong offset:
```csharp
// BROKEN: Reading at offset Length (BEYOND the packet)
if (ClientSeal != BitConverter.ToUInt64(packet, Length))
```

The seal is at the END of the packet, which is at `Length - 8`, not `Length`.

## Fix
```csharp
// FIXED: Reading at offset Length - 8 (end of packet)
if (Length >= 8)
{
    ulong seal = BitConverter.ToUInt64(packet, Length - 8);
    if (ClientSeal != seal)
    {
        Log.Warning("Invalid packet seal from {Name}, ID={ID}, Length={Length}", ...);
        client.Disconnect();
        return;
    }
}
```
