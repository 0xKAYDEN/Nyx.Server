# Fix: GameTimer Disposal Causing Monster Respawn Failure

## Problem
Monsters would disappear when killed and never respawn. The error was:
```
System.ObjectDisposedException: Cannot access a disposed object.
Object name: 'GameTimer`1'
   at Nyx.Server.Game.Screen..ctor(GameClient client)
```

## Root Cause
The `GameTimer<T>.Start()` method was returning `this` (the timer itself) as the subscription:
```csharp
public IDisposable Start(T param)
{
    // ...
    _subscription = ThreadingController.Subscribe(...);
    return this;  // BUG: Returns the timer itself!
}
```

When `Screen.DisposeTimers()` called `TimerSubscriptions[i].Dispose()`, it was actually calling `Dispose()` on the **static** `GameTimer` instance:
```csharp
// Screen.cs constructor
TimerSubscriptions = new IDisposable[] 
{
    MonsterBuffers.Add(client),  // Returns GameTimer itself
    Guards.Add(client),
    AliveMonsters.Add(client),
    Items.Add(client)
};

// When player disconnects, this disposes the static timers!
public void DisposeTimers()
{
    for (int i = 0; i < TimerSubscriptions.Length; i++)
        TimerSubscriptions[i].Dispose();  // Disposes MonsterBuffers, Guards, etc.
}
```

After the first player disconnected, the static timers were disposed forever. No new players could create subscriptions.

## Fix
Created a `TimerSubscription` wrapper class that only disposes the inner subscription, NOT the parent GameTimer:

```csharp
public IDisposable Start(T param)
{
    ObjectDisposedException.ThrowIf(_disposed, this);
    
    var subscription = ThreadingController.Subscribe(...);
    
    // Return a wrapper that only disposes the subscription
    return new TimerSubscription(subscription);
}

private sealed class TimerSubscription : IDisposable
{
    private IDisposable? _inner;
    private int _disposed;

    public TimerSubscription(IDisposable inner)
    {
        _inner = inner;
    }

    public void Dispose()
    {
        if (Interlocked.Exchange(ref _disposed, 1) == 1)
            return;
        _inner?.Dispose();
        _inner = null;
    }
}
```

## Key Changes
1. `GameTimer<T>.Start()` now returns a `TimerSubscription` wrapper instead of `this`
2. `TimerSubscription` only disposes the inner subscription, not the parent timer
3. Static timers (`MonsterBuffers`, `Guards`, `AliveMonsters`, `Items`) can now be reused across multiple players
4. Added `where T : notnull` constraint for safety
