# Fix: Client Disconnecting During DH Handshake

## Problem
Client would disconnect immediately after auth server forwarded it to the game server. The DH key exchange handshake was never completing.

## Root Cause
In `GameSession.Send()`, the use of `Task.Run` to wrap the `SendAsync` call introduced a thread pool scheduling delay. This meant the DH key exchange packet wasn't being sent immediately, causing the client to disconnect before receiving it.

### Backup (working):
```csharp
public void Send(byte[] data)
{
    if (data == null || data.Length == 0) return;
    if (!Alive) return;
    _ = SendAsync(data);  // Direct call - immediate execution
}
```

### Current (broken):
```csharp
public void Send(byte[] data)
{
    // ...
    _ = Task.Run(async () => { await SendAsync(data); });  // Delayed by thread pool scheduling
}
```

## Fix
1. Removed `Task.Run` wrapper from `Send()` method - now calls `SendAsync` directly
2. Removed `throw` from `SocketException` catch in `SendAsync()` to prevent unobserved exceptions
